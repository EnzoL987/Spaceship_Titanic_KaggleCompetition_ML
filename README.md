## 📝 Project Description
This project is my participation in the Kaggle competition ["Spaceship Titanic"](https://www.kaggle.com/competitions/spaceship-titanic). 

The story takes place in the year 2912. The interstellar spaceship *Spaceship Titanic* collided with a spacetime anomaly hidden within a dust cloud during its voyage to 55 Cancri E. The tragic consequence caused nearly half of the 13,000 passengers to be transported to an alternate dimension. 

The goal of this project is to use Data Science skills to solve this cosmic mystery. It involves predicting which passengers were transported using a binary classification algorithm trained on data recovered from the spaceship's damaged computer system.

## 📁 Repository Structure
The project is professionally organized to clearly separate data, code, and final predictions:

* **`.vscode/`**: Local development environment configuration.
* **`Data/`**: Folder containing the raw data provided by Kaggle (`train.csv`, `test.csv`, `sample_submission.csv`).
* **`Notebooks/`**: Jupyter Notebooks detailing the code evolution, from data cleaning and exploratory analysis to model training and evaluation.
* **`Submissions/`**: Prediction files in CSV format generated by the models and ready for Kaggle submission.

## 🧠 Approach and Feature Engineering
Special attention was given to data preparation to provide the algorithms with the most relevant signals:

* **Logical Deductions (Business Logic):** Filling missing values through intelligent cross-referencing. For example, a passenger in `CryoSleep` automatically incurs zero expenses, and conversely, a passenger with active expenses cannot be in `CryoSleep`.
* **Standardization and KNNImputer:** Using a `KNNImputer` on standardized data (Z-score) to accurately fill missing values in continuous variables (Age, Expenses).
* **New Variable Extraction (Feature Engineering):**
    * Splitting the Cabin identifier into 3 distinct variables: Deck (`Deck`), Number (`Num`), and Side (`Side`), followed by ordinal mapping based on the assumed cabin hierarchy.
    * Analyzing the `PassengerId` variable to extract the travel group (`Group`), travel group size (`GroupSize`), identify solo travelers (`IsAlone`), and robustly deduce missing home planets for members of the same group.
* **Encoding & Selection:** Using One-Hot Encoding to transform textual categories (Planets, Destinations) into mathematically usable data, and systematically dropping noisy or redundant features (e.g., `Name`, `VIP`, `Cabin`, and certain destination binaries depending on the model) to improve generalization.

## 🏆 Models and Results (Kaggle Score)
The project's development was divided into three iterative phases, leading to the following results on the Kaggle Leaderboard (measured in Accuracy):

1. **`01_baseline_random_forest.ipynb`**
   * *Model:* Random Forest Classifier optimized via `GridSearchCV`
   * *Approach:* Baseline model to validate the cleaning and initial feature engineering methodology.
   * *Kaggle Score:* **79.541 %** (Top 70%)
   
2. **`02_gradient_boosting_tuning.ipynb`**
   * *Model:* Gradient Boosting Classifier optimized via `GridSearchCV`
   * *Approach:* Advanced Feature Selection (dropping features like `VIP` and certain destinations) and inclusion of new engineered group metrics (`GroupSize`, `IsAlone`).
   * *Kaggle Score:* **80.430 %** *(Current best score and Top 30% competition)*
   
3. **`03_xgboost.ipynb`**
   * *Model:* XGBoost Classifier optimized via `GridSearchCV`
   * *Approach:* Extended hyperparameter grid search (learning rate, subsample) and refined feature selection (dropping `IsAlone` due to redundancy).
   * *Kaggle Score:* **80.219 %** (Top 45%)

## 🚀 How to Run This Project Locally
1. Clone this repository to your machine.
2. Install the required dependencies (you can use `pip install pandas numpy scikit-learn xgboost matplotlib seaborn`).
3. Place the original Kaggle data files in the `Data` folder.
4. Open the files in the `Notebooks` folder using VS Code or Jupyter. The relative import paths will correctly read the data from `Data` and export your predictions to `Submissions`.
